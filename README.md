## About VulnScanner

VulnScanner is a production-hardened educational web vulnerability scanner designed to help users understand and analyze web application security issues. It provides a secure platform for performing vulnerability assessments with a FastAPI backend and Next.js frontend.

The project focuses on secure application design, including authenticated scanning workflows, safe target validation, API security, and modern deployment practices. It demonstrates real-world concepts such as vulnerability assessment, secure coding, data protection, and scalable web application architecture.

Built with **FastAPI, Next.js, TypeScript, and PostgreSQL**, VulnScanner is suitable for security learning, experimentation, and authorized vulnerability testing environments.
